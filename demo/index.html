Dialed In

Muse Glimmer-30B listens unevenly. Slow patterns in a text pass through its attention heads more strongly than fast ones. We measured that lean, trained a dial that turns it down, traced the dial to one layer, and let Muse run the lab that asks what to test next.

1 · The dial

Turn the lean down

We add a faint sine wave with a period of N tokens to the model's hidden states and read how strongly each head carries it. Gain climbs with the period: the model favors slow patterns. The dial is a small trained adapter. Each setting below was measured on five books.

3 · The lab loop

Muse as the scientist

Muse Spark narrates results and critiques designs. Muse Wonder proposes the next experiment and reviews the code. A person seals each pre-registered spec before the GPU runs it. Every number Muse writes must match a cited fact from the result files.
